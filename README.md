## 📚 Topics Covered

| Folder | Description |
|---------|-------------|
| **01-basics** | Variables, constants, namespaces, operators, user input, type conversion, math functions |
| **02-control-flow** | If statements, switch, loops, logical operators, break & continue |
| **03-functions** | Functions, return values, overloading, recursion, templates, scope |
| **04-arrays** | Arrays, searching, sorting, multidimensional arrays |
| **05-pointers-memory** | Memory addresses, pointers, null pointers, dynamic memory |
| **06-structures-enums** | Structures, enums, passing structures |
| **07-object-oriented-programming** | Classes, constructors, inheritance, getters & setters |
| **08-templates-stl** | STL containers, algorithms, lambda expressions *(in progress)* |
| **09-file-handling** | Reading, writing and managing files *(in progress)* |
| **10-projects** | Hands-on C++ practice projects |
| **11-dsa** | Data Structures & Algorithms *(planned)* |
| **notes** | Personal notes and revision material |

## ▶️ Compile & Run

Compile a source file:

```bash
clang++ filename.cpp -std=c++17 -o program
```

Run the executable:

```bash
./program
```
